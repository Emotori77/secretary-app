# 秘書りな — Personal AI Secretary

Node.js の標準機能だけで動く、近未来型のパーソナルAI秘書アプリです（追加インストール不要）。
「記録するだけ」ではなく、状況を見て**先回りして提案する**ことを目指しています。

## 主な機能
- **ホーム（今日の司令室）**：時間帯の挨拶／今やること1件を大きく表示／進捗率・未完了数・りなのブリーフィング／前日の予定リマインダー
- **タスク**：詳細・期限・優先度・カテゴリ・所要時間・サブタスク・繰り返し・関連目標・延期回数など14項目。絞り込み（今日/今週/期限切れ/完了済み/カテゴリ別）。「りなに分解してもらう」
- **予定（カレンダー）**：月／週／日表示、持ち物・準備・通知、重複警告。将来のGoogleカレンダー連携を想定した構造
- **りな（AI秘書チャット）**：自然文からタスク/予定の追加候補を作成。**変更前に必ず確認カード**（現在はルールベース簡易版。LLM接続で本格化）
- **記録**：メモ（カテゴリ・タグ・固定・検索・並び替え・りなに整理）／デイリーレビュー（5段階の気分・満足度・りなのコメント）／週次振り返り／目標（進捗・りなに計画作成）／通知設定
- **通知**：予定前・期限・朝夜・週次など。ブラウザ通知＋アプリ内通知
- **デザイン**：白黒グレー＋淡い青紫、ガラス表現、ライト/ダーク、抽象オーブ・アバター（状態表現）、スマホ最優先、**PWA対応**

## 使い方
1. このフォルダへ移動：`cd "secretary-app"`
2. 起動：`node server.js`
3. ブラウザで `http://localhost:3000` を開く（スマホは同じWi-Fiで `http://<MacのIP>:3000`）
4. 停止：`Ctrl + C`

## データ
- すべて `data.json` に保存（アプリを閉じても消えません）。
- スキーマは後方互換で拡張されており、既存データは読み込み時に自動で新形式へ補完されます。

## ファイル構成
- `server.js` … APIサーバー（データ保存・読み込み・PWA配信）
- `index.html` … 画面＋クライアント（SPA）
- `data.json` … 保存データ（自動生成）

## 今後（LLM接続）
「りな」チャットを本物のAIにするには、サーバー側にLLMのAPIキーを設定し、`/api/chat` を追加する構成に差し替えます。**APIキーはフロントには書かず、サーバー側で保持**します。
